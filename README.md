# File Forge — Releases

Download the latest File Forge APK from the releases on this repo.

File Forge is a file manager and APK editor for Android: browse and manage files, edit code and resources inside APKs (Smali, XML, DEX, hex), inspect any APK's permissions and contents, compare two APKs, clone an app, merge split APK bundles (.apks / .xapk) into one installable APK, and sign your modified copies. Includes batch tools, archive tools, a 30-day Trash with undo, and a signing ledger that records every key and signature. Works fully offline — no account, no internet needed.
